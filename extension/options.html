memsave

Расширение Chrome для отправки картинок в личный архив.

Сервер

Для доступа через Cloudflare Access сначала откройте memsave в браузере и войдите. Пункт «Отправить в memsave» появится в контекстном меню при правом клике на картинке. Если сайт картинки не даёт скачать файл, расширение попросит memsave получить превью по ссылке.

Версии

Расширение:

Версия сервера и короткий коммит приходят из /api/version.
